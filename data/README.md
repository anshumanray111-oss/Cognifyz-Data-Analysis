## Dataset Setup

The original CSV is excluded from this GitHub repository because of its size.

1. Obtain the original Cognifyz restaurant dataset separately.
2. Place it inside this `data/` directory.
3. Rename it to `Dataset_real.csv` if necessary.

Expected location:

Cognifyz-Data-Analysis/
└── data/
    ├── Dataset_real.csv
    └── README.md

Both notebooks use a relative-path loader to locate the dataset.

Make sure the dataset is present before running either notebook.
