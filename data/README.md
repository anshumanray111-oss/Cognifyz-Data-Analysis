# Dataset Directory

Place `Dataset.csv` here.

The dataset used in this project is the official Cognifyz Data Analysis internship dataset containing 9,557 rows and 21 columns of restaurant data across multiple countries.

Both notebooks are configured to automatically check:
1. `../data/Dataset.csv` (when running from `Level_1/` or `Level_2/` directory)
2. `data/Dataset.csv` (when running from project root)
3. Direct session upload paths
